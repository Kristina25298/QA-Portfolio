# Баг-репорты по авторизации

## BUG-007 Авторизация с пустым логином

**Severity:** Critical

**Шаги воспроизведения:**

1. Открыть страницу входа.
2. Оставить логин пустым.
3. Ввести пароль.
4. Нажать кнопку «Войти».

**Фактический результат:**
Запрос отправляется на сервер.

**Ожидаемый результат:**
Отображается сообщение о необходимости заполнить логин.

---

## BUG-008 Авторизация с пустым паролем

**Severity:** Critical

**Шаги воспроизведения:**

1. Ввести логин.
2. Оставить пароль пустым.
3. Нажать кнопку «Войти».

**Фактический результат:**
Запрос отправляется.

**Ожидаемый результат:**
Отображается сообщение о необходимости заполнить пароль.

---

## BUG-009 Отсутствует блокировка после многократного ввода неверного пароля

**Severity:** Major

**Шаги воспроизведения:**

1. Несколько раз ввести неверный пароль.
2. Нажать кнопку «Войти».

**Фактический результат:**
Количество попыток не ограничено.

**Ожидаемый результат:**
Учетная запись временно блокируется либо появляется CAPTCHA.

---

## BUG-010 Сообщение об ошибке не очищается после успешного входа

**Severity:** Minor

**Шаги воспроизведения:**

1. Ввести неверный пароль.
2. Получить сообщение об ошибке.
3. Выполнить успешный вход.

**Фактический результат:**
Сообщение об ошибке продолжает отображаться.

**Ожидаемый результат:**
Сообщение исчезает после успешной авторизации.
