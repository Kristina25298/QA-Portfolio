# Чек-лист авторизации пользователя

## Отображение формы входа

* Открывается страница авторизации
* Отображается поле Email/Логин
* Отображается поле Пароль
* Отображается кнопка «Войти»
* Отображается ссылка «Забыли пароль»

## Проверка поля Логин

* Ввод корректного логина
* Ввод несуществующего логина
* Пустое поле логина
* Ввод логина с пробелами
* Ввод логина в разном регистре

## Проверка поля Пароль

* Ввод корректного пароля
* Ввод неверного пароля
* Пустое поле пароля
* Проверка маскирования символов пароля

## Авторизация пользователя

* Успешный вход с валидными данными
* Вход с неверным логином
* Вход с неверным паролем
* Вход с пустыми обязательными полями
* Проверка отображения сообщений об ошибках

## Работа с сессией

* Пользователь остается авторизованным после обновления страницы
* Корректный выход из системы
* Доступ к защищенным разделам после авторизации
* Ограничение доступа после выхода из системы

## Обработка ошибок

* Отображение сообщения при неверных учетных данных
* Отображение сообщения при недоступности сервера
* Корректная обработка нескольких неудачных попыток входа
