# Тест-кейсы регистрации пользователя

## TC-001 Успешная регистрация нового пользователя

**Предусловие:** Пользователь не зарегистрирован в системе.

**Шаги:**

1. Открыть страницу регистрации.
2. Ввести корректный email.
3. Ввести корректный пароль.
4. Подтвердить пароль.
5. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Пользователь успешно зарегистрирован и перенаправлен на главную страницу.

---

## TC-002 Регистрация с пустым полем Email

**Шаги:**

1. Открыть страницу регистрации.
2. Оставить поле Email пустым.
3. Заполнить остальные обязательные поля.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Отображается сообщение о необходимости заполнить поле Email.

---

## TC-003 Регистрация с некорректным Email

**Шаги:**

1. Открыть страницу регистрации.
2. Ввести email без символа @.
3. Заполнить остальные поля.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Отображается сообщение о некорректном формате email.

---

## TC-004 Регистрация с несовпадающими паролями

**Шаги:**

1. Ввести корректный email.
2. Ввести пароль.
3. Ввести другой пароль в поле подтверждения.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Отображается сообщение о несовпадении паролей.

---

## TC-005 Регистрация с уже существующим Email

**Предусловие:** Email уже зарегистрирован в системе.

**Шаги:**

1. Открыть страницу регистрации.
2. Ввести зарегистрированный email.
3. Ввести корректный пароль.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Отображается сообщение о том, что пользователь уже существует.

---

## TC-006 Проверка минимальной длины пароля

**Шаги:**

1. Открыть страницу регистрации.
2. Ввести корректный email.
3. Ввести пароль короче минимально допустимой длины.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Отображается сообщение о несоответствии требованиям к паролю.
