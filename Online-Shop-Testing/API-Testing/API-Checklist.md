# Чек-лист API тестирования

## Проверка статус-кодов

- Успешный запрос возвращает 200 OK
- Создание ресурса возвращает 201 Created
- Неверные данные возвращают 400 Bad Request
- Неавторизованный доступ возвращает 401 Unauthorized
- Несуществующий ресурс возвращает 404 Not Found
- Ошибка сервера возвращает 500 Internal Server Error

## Проверка регистрации пользователя

- Регистрация с валидными данными
- Регистрация с пустым email
- Регистрация с пустым паролем
- Регистрация с уже существующим email
- Проверка обязательных полей

## Проверка авторизации

- Авторизация с валидными данными
- Авторизация с неверным паролем
- Авторизация с несуществующим пользователем
- Авторизация с пустыми полями
- Получение токена после успешного входа

## Проверка каталога товаров

- Получение списка товаров
- Получение товара по ID
- Получение несуществующего товара
- Проверка структуры ответа

## Проверка данных ответа

- Ответ соответствует JSON-формату
- Присутствуют обязательные поля
- Типы данных соответствуют спецификации
- Отсутствуют лишние поля

## Проверка времени ответа

- Время ответа не превышает допустимого значения
- API корректно обрабатывает повторные запросы
