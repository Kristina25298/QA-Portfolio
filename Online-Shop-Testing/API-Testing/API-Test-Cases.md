# Тест-кейсы API

## TC-API-001 Успешная регистрация пользователя

**Предусловие:** Пользователь не зарегистрирован в системе.

**Шаги:**
1. Отправить POST-запрос на эндпоинт регистрации.
2. Передать валидный email.
3. Передать валидный пароль.

**Ожидаемый результат:**
- Статус-код 201 Created.
- Пользователь успешно создан.
- В ответе возвращается информация о пользователе.

---

## TC-API-002 Регистрация с пустым email

**Шаги:**
1. Отправить POST-запрос на регистрацию.
2. Оставить поле email пустым.
3. Передать валидный пароль.

**Ожидаемый результат:**
- Статус-код 400 Bad Request.
- Отображается сообщение об ошибке валидации.

---

## TC-API-003 Успешная авторизация

**Предусловие:** Пользователь зарегистрирован в системе.

**Шаги:**
1. Отправить POST-запрос на авторизацию.
2. Передать корректные учетные данные.

**Ожидаемый результат:**
- Статус-код 200 OK.
- Возвращается токен авторизации.

---

## TC-API-004 Авторизация с неверным паролем

**Предусловие:** Пользователь зарегистрирован в системе.

**Шаги:**
1. Отправить POST-запрос на авторизацию.
2. Ввести корректный логин.
3. Ввести неверный пароль.

**Ожидаемый результат:**
- Статус-код 401 Unauthorized.
- Возвращается сообщение об ошибке.

---

## TC-API-005 Получение списка товаров

**Шаги:**
1. Отправить GET-запрос на получение списка товаров.

**Ожидаемый результат:**
- Статус-код 200 OK.
- Возвращается список товаров.
- Ответ соответствует JSON-формату.

---

## TC-API-006 Получение товара по ID

**Шаги:**
1. Отправить GET-запрос на получение товара по существующему ID.

**Ожидаемый результат:**
- Статус-код 200 OK.
- Возвращаются данные выбранного товара.

---

## TC-API-007 Получение несуществующего товара

**Шаги:**
1. Отправить GET-запрос с несуществующим ID товара.

**Ожидаемый результат:**
