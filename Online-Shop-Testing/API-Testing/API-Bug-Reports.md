# Баг-репорты API

## BUG-API-001 Некорректный статус-код при неверном пароле

**Severity:** High

**Предусловие:**
Пользователь зарегистрирован в системе.

**Шаги воспроизведения:**
1. Отправить POST-запрос на эндпоинт авторизации.
2. Передать корректный логин.
3. Передать неверный пароль.

**Фактический результат:**
Сервер возвращает статус-код 200 OK.

**Ожидаемый результат:**
Сервер должен возвращать статус-код 401 Unauthorized.

---

## BUG-API-002 Регистрация пользователя без email

**Severity:** Critical

**Шаги воспроизведения:**
1. Отправить POST-запрос на регистрацию.
2. Не передавать поле email.
3. Передать остальные обязательные данные.

**Фактический результат:**
Пользователь успешно создается.

**Ожидаемый результат:**
Сервер должен вернуть ошибку валидации и статус-код 400 Bad Request.

---

## BUG-API-003 Отсутствует сообщение об ошибке при невалидных данных

**Severity:** Medium

**Шаги воспроизведения:**
1. Отправить запрос с некорректными данными.
2. Получить ответ сервера.

**Фактический результат:**
Возвращается пустое тело ответа.

**Ожидаемый результат:**
Возвращается понятное сообщение об ошибке.

---

## BUG-API-004 Получение товара с несуществующим ID

**Severity:** Medium

**Шаги воспроизведения:**
1. Отправить GET-запрос с несуществующим ID товара.

**Фактический результат:**
Сервер возвращает статус-код 200 OK.

**Ожидаемый результат:**
Сервер должен вернуть статус-код 404 Not Found.

---

## BUG-API-005 Некорректный формат ответа

**Severity:** Medium

**Шаги воспроизведения:**
1. Отправить запрос на получение списка товаров.

**Фактический результат:**
Некоторые поля отсутствуют либо имеют неверный тип данных.

**Ожидаемый результат:**
Ответ соответствует спецификации API и содержит все обязательные поля.

---

## BUG-API-006 Повышенное время ответа API

**Severity:** Low

**Шаги воспроизведения:**
1. Отправить запрос на получение списка товаров.
2. Замерить время ответа.

**Фактический результат:**
Время ответа превышает 5 секунд.

**Ожидаемый результат:**
Время ответа не превышает допустимых значений согласно требованиям.
